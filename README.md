# АКОС — 2026

Индивидуальные задания по курсу «Архитектура компьютера и операционные системы».

## ИДЗ №1

Вариант 15 — «Задача о нелюдимых садовниках».

Последовательная имитационная программа на C для Linux. Исходный код, демонстрационные карты и проверки находятся в папке `IDZ/IDZ1/`.

[Отчёт по ИДЗ №1](IDZ/IDZ1/report/REPORT.md).

Сборка через CMake и запуск тестов в Ubuntu:

```bash
cmake --preset debug
cmake --build --preset debug
ctest --preset debug
```

В VS Code откройте репозиторий или папку задания в **WSL: Ubuntu**, выберите пресет `debug`. **Ctrl+Shift+B** — сборка, **F5** — демонстрация с отладкой. Подробные команды, формат входного файла и проверки находятся в [README задания](IDZ/IDZ1/README.md).
