# ИДЗ №1 — нелюдимые садовники

Вариант 15. Последовательная программа на C для Linux/WSL: два садовника обходят клеточный сад, перемещаются, ждут друг друга и обрабатывают доступные клетки.

## Запуск

Из этой папки:

```bash
cmake --preset debug
cmake --build --preset debug
./build/cmake-debug/gardeners data/demo.txt
```

Из корня `akos`:

```bash
cmake --preset debug
cmake --build --preset debug
./build/cmake-debug/IDZ/IDZ1/gardeners IDZ/IDZ1/data/demo.txt
```

В VS Code нужно открыть проект через **WSL: Ubuntu**. `Ctrl+Shift+B` собирает программу, `F5` запускает её с отладчиком. В PowerShell из этой папки можно выполнить `./run.ps1`.

## Входной файл

```text
строки столбцы
время_перехода_1 время_перехода_2 время_обработки
C_или_R обходы_0_или_1
строка_1 столбец_1 строка_2 столбец_2
задержка_кадра_в_мс
карта из . и #
```

`.` — доступная клетка, `#` — препятствие. Координаты начинаются с нуля. В `C` второй садовник идёт по столбцам, в `R` — по строкам. `1` разрешает обходы, `0` запрещает. Пример — `data/demo.txt`.

В терминале карта обновляется по тактам: `1` и `2` — садовники, `+` — обработанные клетки. Полная история работы сохраняется в `garden.log` в текущей папке. `Ctrl+C` корректно прерывает моделирование.
